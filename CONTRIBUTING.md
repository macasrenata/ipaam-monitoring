# Contributing to Tree Monitoring App

Thank you for your interest in contributing to Tree Monitoring App. 🌳

Tree Monitoring App is an open-source environmental monitoring project focused on supporting the analysis of licensed logging activities in the Brazilian Amazon.

Contributions from developers, researchers, environmental specialists, GIS professionals, and data scientists are welcome.

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Improving accessibility and UX
* Adding or improving environmental datasets
* Improving geospatial analysis
* Improving satellite data processing
* Fixing issues
* Submitting pull requests

## Development Setup

Fork the repository and clone your fork:

```bash
git clone https://github.com/YOUR_USERNAME/ipaam-monitoring.git
cd ipaam-monitoring
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Creating a Branch

Create a branch for your change:

```bash
git checkout -b feature/my-feature
```

For bug fixes:

```bash
git checkout -b fix/my-fix
```

Use descriptive branch names whenever possible.

Examples:

```text
feature/add-map-filter
feature/satellite-layer
fix/csv-export
docs/improve-readme
```

## Before Submitting a Pull Request

Make sure the project runs correctly and that your changes do not break existing functionality.

When available, run:

```bash
npm run lint
npm run build
```

## Pull Requests

Pull requests should clearly describe:

* What was changed
* Why the change was necessary
* How the change was tested
* Screenshots when the change affects the UI

Keep pull requests focused on a single change whenever possible.

## Issues

Before creating a new issue, please check whether a similar issue already exists.

When reporting a bug, include:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Browser or environment information
* Screenshots when applicable
