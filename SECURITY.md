# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

If you discover a security vulnerability in Tree Monitoring App, please report it privately to the project maintainers.

Please include as much information as possible, including:

* Description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Affected componentss
* Suggested mitigation, if available

Security reports will be reviewed and addressed as appropriate.

## Supported Versions

Tree Monitoring App is currently under active development.

Security fixes are generally applied to the latest version of the project.
